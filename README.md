# spr-block0

Asynchronous Block 0 for ATHP 6190 Spine & Postural Restoration (UIW MSAT, Fall 2026). A static site on GitHub Pages: ten gated lessons, answers checked in the browser, progress kept in the student's own browser, certificate on completion.

## How the site is built

| File | What it is | Who edits it |
| --- | --- | --- |
| `data/lessons.json` | Lesson titles, framing text, "Where to look" links, dates, course info, term salt | Edited directly |
| Answer key `.xlsx` | Every graded item: prompt, options, accepted answers, sources, page lookups | Instructors, on OneDrive. **Never committed** |
| `data/content.json` | Generated: `lessons.json` plus items from the key, with answers stored only as salted SHA-256 hashes | Generated by `tools/build_content.py`; do not edit |
| `js/check.js` | Answer normalization and hashing (must match `build_content.py`) | Code |
| `js/app.js` | Rendering, gating, progress, export/import | Code |
| `tools/make_lesson_pages.py` | Regenerates the thin `lessons/*.html` wrappers | Run after adding a lesson |

## Changing an answer

1. Edit the answer key spreadsheet (accept column, options, source, or a page number on the Pages sheet).
2. Rebuild: `python3 tools/build_content.py path/to/answer-key.xlsx`. It refuses to write if an accepted answer is not one of the options or a cell id repeats.
3. Test: serve the folder (`python3 -m http.server 8765`) and run `python3 tools/smoke_test.py path/to/answer-key.xlsx`. It fails one item three times per lesson, then passes every lesson from the key.
4. Commit `data/content.json` to `dev`.

Changing an accepted answer after students have passed a lesson does not un-pass them; the change applies to the next check.

## Branches and launch

- `dev`: all work. Instructor preview is published from here.
- `main`: what GitHub Pages serves. Empty until launch.
- Launch: set `"preview": false` in `data/lessons.json`, rebuild, merge `dev` into `main`, enable Pages (Deploy from branch, `main`, root).
- Each term: rotate `salt` in `lessons.json` and rebuild.

## Security model

Answers are hashed, not encrypted. With two or three options per item, a determined student with developer tools can recover them. The design accepts that: the certificate is pass/fail, and the in-person units expose anyone who skipped the work. See the Build Spec.
